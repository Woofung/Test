跨裝置同步設定

使用 GitHub Gist 在不同裝置之間同步紀錄。設定一次以後，每次完成測驗會自動上傳；其他裝置打開首頁時會自動下載最新紀錄。 不設定也可以使用，紀錄就只會存在這台裝置。

第一次設定步驟：
① 到 GitHub Token 頁面 產生一個 Token（只勾「Gists」權限）
② 到 gist.github.com 建立一個新的 Gist（內容隨便填、設成 Secret），複製網址裡的 Gist ID
③ 把 Token 跟 Gist ID 貼到下面
